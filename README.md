# Web-программирование (PHP)

## Содержание

### 1. Классы и интерфейсы
- Основы ООП в PHP
- Создание классов, наследование, инкапсуляция, полиморфизм
- Реализация интерфейсов и абстрактных классов

### 2. Шаблоны проектирования
- Изучение и применение паттернов проектирования (Singleton, Factory, Observer и др.)
- Практическая реализация на PHP

### 3. Использование ООП с базой данных SQLite
- Объектно-ориентированный подход к работе с БД
- Создание моделей данных и DAO-паттерн
- Интеграция с SQLite

### 4. Standard PHP Library (SPL)
- Использование встроенных структур данных SPL
- Итераторы, массивы, очереди, стеки
- Автозагрузка классов (SplAutoloader)

### 5. Обработка XML
- Парсинг и генерация XML-документов
- Работа с DOMDocument, SimpleXML
- Transformations (XSLT)

### 6. PHP Data Objects (PDO)
- Универсальный интерфейс доступа к базам данных
- Подготовленные выражения (prepared statements)
- Защита от SQL-инъекций

### 7. Работа с библиотекой GD
- Программное создание и обработка изображений
- Генерация графиков, CAPTCHA, водяных знаков
- Манипуляции с пикселями и цветами

### 8. Использование MVC фреймворка
- Архитектура Model-View-Controller
- Разделение логики и представления
- Построение веб-приложения по принципам MVC

---

## Используемые технологии

- **PHP 7/8** – основной язык программирования
- **HTML5/CSS3** – разметка и стилизация веб-страниц
- **SQLite** – реляционная база данных
- **PDO** – интерфейс доступа к БД
- **SPL** – стандартная библиотека PHP
- **GD Library** – обработка изображений
- **XML/DOM** – работа с XML-документами
- **MVC** – архитектурный паттерн
